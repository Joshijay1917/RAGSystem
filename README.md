# ChatAI

**Visit Now:** **https://my-ragsystem-app.vercel.app**

A mini RAG workspace where users upload documents and ask questions.

## Features
- Upload text files
- Embedding storage in MongoDB
- Semantic search
- AI answers with sources
- Real-time agent events via Socket.io
- Status page

## Tech
- React + Tailwind
- Node.js + Express
- MongoDB
- Gemini API
- Socket.io

# Private Knowledge Q&A

A mini RAG workspace where users upload documents and ask questions.

## Features
- Upload text files
- Embedding storage in MongoDB
- Semantic search
- AI answers with sources
- Real-time agent events via Socket.io
- Status page

## Tech
- React + Tailwind
- Node.js + Express
- MongoDB
- Gemini API
- Socket.io

## Run locally

### Backend
npm install  
npm run dev  

### Frontend
npm install  
npm run dev
